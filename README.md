# AES Image Hunt

Hidden messages are locked inside encrypted pictures. Unlock them with code!

Install the two helpers (once):  `pip install pillow pycryptodome`

**Level 1:** run `python decrypt.py`, then open `revealed.png`.
Then change one letter of `KEY` and run it again. What happens?

**Level 2:** open `crack_the_pin.py` and fill in the one line marked `YOUR TURN`.
Run `python crack_the_pin.py`, then open `vault_open.png`.
